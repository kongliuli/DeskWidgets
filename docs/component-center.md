# 组件中心与本地实用卡片

入口：双击托盘 DeskWidgets 图标，或右键 →「组件中心 / 快速启动」。原「加载挂件」菜单保留；双击现在打开组件中心，重载仍在右键菜单。

组件中心现在是单页流式布局，不再把插件库与运行实例拆成两个页签。运行中的类型排在前面，每张卡片显示图标、用途、未开启/已开启数量，实例直接列在卡片内。上方提供“全部 / 已开启 / 未开启”筛选及名称、目录搜索；中文展示名也能搜索，回车唤醒首个结果。“＋ 打开组件”启动第一份，“＋ 新建实例”用于多开。

每个运行实例有独立的置顶显示、锁定/解锁、置顶/沉底、重载、关闭按钮。置顶显示会明确改变该实例置顶状态，并最小化组件中心，便于找到被应用遮挡的卡片；不会修改位置。要恢复桌面层，请点图钉切回沉底。共享列表在布局持久化或插件文件变更后刷新，关闭中心不退出宿主。全局重载仍保留在托盘右键菜单。

视觉：石墨蓝底色、浅蓝操作色、柔和绿色运行标记。组件种类使用原生矢量线条图标，未知插件使用通用组件图标；图标不依赖联网资源。应用与托盘使用 assets/deskwidgets.ico，包含 16/20/24/32/48/64/128/256 像素。卡片说明是功能摘要，不冒充实时监控数据，也不额外创建 WebView 来生成缩略图。

新卡片均不自动添加到用户现有布局；从组件中心启动。插件仍在 widgets 子目录，纯 ES Modules、无 npm，复用共享拖拽/锁定/外观设置。实例各自独立 WebView2 profile，便签、日程、专注和入口保存在各实例 localStorage。

- 日程倒计时：一个实例对应一个本地事件，选择本机时区日期时间；到期后显示已经过去。需要多个日程时新建实例。本版无 ICS/CalDAV/云账号与提醒推送。
- 媒体播放：读取 Windows GlobalSystemMediaTransportControlsSessionManager 的当前公开会话，每秒更新标题、作者、应用与播放状态；点击控制上一首/播放暂停/下一首。播放器没有接入系统媒体会话或系统拒绝访问时显示实际状态。未接入播放器不会被当作支持。无音频采集、歌词服务或账号登录。
- 轻量便签：纯文本，输入停止 400 ms 自动保存，失焦与页面退出补存；存储失败显示错误。锁定后禁止输入，只留解锁控制。无云同步/Markdown HTML 渲染。
- 工作区快捷入口：每实例最多 30 项，手工填写名称及本机文件夹、已有 .lnk 或 HTTP(S) URL。逐项可删。仅明确点击才使用 Windows ShellExecute；拒绝 UNC/设备路径、脚本、直接 EXE、自定义协议和网址凭据。不解析 .lnk 的内部目标，快捷方式应由用户自行确认可信；本版无自动扫描/批量启动。
- 专注与短待办：一个目标加 1–240 分钟计时，可暂停/重置。期限使用时间戳，后台暂停渲染不影响进度，重开实例继续。无待办清单、系统通知或声音。

网络监控、开发服务健康和磁盘卡按本轮要求暂缓。

验证入口：dotnet build；tests/host-smoke.ps1 使用独立临时副本及独立 profile，覆盖新插件初始化、纯文本与实例隔离、锁定、日程保存、专注暂停、快捷入口校验与桥接、原生媒体读取尝试、组件中心打开。测试模式不实际启动外部程序、不发送播放器控制。


## 四图、历史便签与全局布局

系统资源在卡片内部可用尺寸达到 620×420 CSS px 时自动显示进度条、雷达、独立环形和两分钟折线四宫格；缩回后恢复用户原选图表。四图共用同一份两秒采样与历史，不创建额外采样器。少于三项指标时雷达位置显示启用提示。

随手记仍自动保存当前草稿；新增“保存到历史”和“历史便签”。历史使用输出目录 notes-history.json 原子写入，并保留上一版本 .bak，与当前草稿分开存储。任意随手记实例都能查看全文、拖出、收回桌面便签或删除未展示的历史。删除历史是明确删除操作；关闭桌面便签不删除历史。长内容固定区域裁切，可在历史中查看全文。

拖出后是无 WebView 的 WPF 纯文本便签，桌面底层、点击穿透、不可选中，不附带拖动/关闭按钮。通过随手记历史中的“关闭桌面便签”收回。退出宿主后下次启动自动恢复，关闭创建它的随手记不会收回。拖出过程中 Esc、丢失指针捕获、锁定/关闭源随手记会取消未提交便签。桌面便签的位置保存为物理屏幕像素，尺寸保存为 WPF DIPs；普通组件 config.json 继续使用 DIPs。

组件中心上方与托盘菜单均提供“从右侧排列”和“全部缩到最小”。排列使用鼠标所在屏幕的工作区，从右上角向下排，放满一列后向左换列，预留 12 物理像素间隔；只改变位置，包含桌面历史便签。放不下或有超大组件时整批不移动，并给出说明。全部缩到最小使用各插件最小宽高，历史桌面便签使用 240×140，保持位置不变。两项均为显式全局操作，也作用于锁定组件，不改变锁定/置顶状态；缩小后不会自动再排列。


## 剪贴板与虚框缩放

从组件中心打开“剪贴板缓存”后开始缓存文本、链接和图片，新实例默认置顶，可通过图钉改成桌面层。默认“随卡片大小自动”，始终采用单列、每条一行的紧凑列表，按可用高度自然显示多条，超出部分可滚动查看（最多缓存 100 条）；加宽不会分列，图片使用行内小缩略图；也可设置最多 3/4/5 条。旧实例的手动上限会保留。文本预览不换行，超出宽度显示省略号；原文不截断，点击仍复制完整内容；点击复制完整原文或原分辨率图片，随后用户自行粘贴。没有自动粘贴、键盘模拟或目标窗口切换。历史与搜索可查本次运行最多 100 条缓存。去重后最近内容排在前面；自行点选复制不会生成重复记录。清空只清宿主缓存，不清系统剪贴板。

图片支持注册的 PNG 格式与 Windows 位图（CF_BITMAP / CF_DIB / CF_DIBV5）读取；位图使用 WPF 官方接口转成 PNG，不自行实现位图解码器。图像复制数据同时提供 PNG 和位图，保留像素尺寸与透明通道。预览仅生成不超过 640×400 的缩略图，通过宿主拦截的 clipboard.images.local 私有资源地址按需供给，不启动 HTTP 服务、不把整张原图反复塞入网页消息。图片区使用 contain 缩放，不裁切原图。文件管理器中仅复制图片文件路径的 CF_HDROP 不等同于复制图片像素，本版不读取文件列表。

本版只保留运行期间的内存缓存，关闭卡片后暂停监听，重开卡片能继续访问本次缓存；退出宿主即清空。多个开启且未暂停的实例共用一个独立 STA 线程与一个原生通知监听器。普通应用遮挡时仍缓存，前端隐藏时暂缓列表重建；前台全屏时按统一休眠策略暂停。多个实例中暂停某一张不会停用其他仍开启的实例。没有变化时不轮询；系统剪贴板被占用时有次数上限的短暂重试。文本单条最多 1 MiB UTF-16 分配容量；图片 PNG 最大 16 MiB、像素总量最大 16×1024×1024；总缓存最多 64 MiB（原图、缩略图及文本合计）。超出单条上限会整条拒绝并显示原因，不截断保存。暂不支持跨重启保存、收藏或云同步。来源声明 ExcludeClipboardContentFromMonitorProcessing 或 CanIncludeInClipboardHistory=0 时跳过缓存；这不代表所有敏感内容都能被自动识别。

缩放使用八向原生 WPF 命中区：四边 10 DIP、上角 16 DIP、下角 30 DIP，右下角有可见斜线抓手。下角为三角形命中区，避开内侧页脚按钮。拖动期间仅更新独立虚框，组件窗口和 WebView 尺寸保持原样，松手一次性应用；Esc、丢失捕获、锁定或关闭窗口会取消。保留插件最小宽高和原生物理坐标换算；混合 DPI 多屏仍需实机检查。此策略减少连续缩放 WebView 的重排与纹理重建，没有承诺量化的 CPU/GPU 降幅。

测试模式不读取或写入用户系统剪贴板：使用生成的 PNG、透明像素与文本夹具，验证复制的数据格式、图片原始尺寸、缩略图资源、内存边界和排版；仍测试实际原生监听注册/解除。

## 全屏统一休眠

宿主每 500 ms 检查前台窗口是否占满其所在显示器，连续两次符合后统一休眠全部屏幕上的组件（含置顶卡片及只读桌面便签）；退出条件后下一次检查唤醒。忽略桌面、任务栏、自身窗口及带标题栏的普通最大化窗口，因此普通窗口最大化不触发。根据前台窗口几何判断，不注入游戏，也不更改应用、电源或系统全屏设置。特殊独占模式、覆盖层或非常规窗口仍需实际验证。

休眠会取消正在进行的拖动/缩放，隐藏窗口与 WebView 以停止画面合成，请求 WebView2 TrySuspendAsync 挂起页面计时器与动画，并暂停组件内正在播放的背景媒体。原生 CPU/GPU/内存、音量/电平、媒体会话与剪贴板订阅均解除；只保留轻量的唤醒检测。休眠期间的前端文件重载会延后。已发出的异步操作允许收尾，不反复开启新的采样。专注、时钟、日程按真实时间计算，休眠不修改业务时间戳；媒体控制卡不会暂停其他应用播放的音乐。

唤醒后恢复页面与先前播放中的组件背景媒体，重新订阅原生服务，保持尺寸、坐标、锁定和置顶偏好。若显示器已经移除，完全离屏窗口会按现有规则回到可用工作区。剪贴板原有缓存不丢失，全屏期间不持续采集，恢复时读取当前项。

实际集成检查覆盖 CoreWebView2.IsSuspended、页面心跳停止、原生订阅数归零、桌面便签隐藏、布局不变与连续唤醒。检测的几何条件有独立测试；这些测试不等于所有游戏和全屏软件已兼容。


## 世界时钟与天气的统一入口

组件中心与托盘把 UTC、北京、纽约、洛杉矶合并成一项“世界时钟”，把旧天气和动态天气合并成一项“天气”。每类卡片汇总该类的所有实例，并显示实例的实际地区/城市；搜索也覆盖地区名称。旧时区实例实际加载同一个 world-clock 源目录，修改主时钟的 HTML/CSS/JS 会同时重载所有地区实例；旧目录作为配置兼容别名保留，Scan 仍可用于恢复旧配置，但 Catalog 只展示合并后的 11 类入口。已有窗口 ID、位置、大小、profile 与 localStorage 不改名、不迁移、不合并，也不关闭任何旧实例。

新建世界时钟先弹出地区下拉框；窗口顶部也能直接下拉切换 UTC、北京、美东纽约、美西洛杉矶。选择写入该实例本地设置，同时更新宿主的地区元数据，默认夜景随地区变化，自定义图片/视频保留。锁定时下拉框隐藏，仍显示只读地区名称。

新建天气先弹出城市选择框，可选南京、北京、上海、广州、深圳、纽约、洛杉矶、伦敦、东京，也可通过 Open-Meteo 搜索其他城市，结果区分省州和国家。新实例默认使用动态天气引擎，已有旧天气继续运行原界面。每张天气卡保持独立城市，之后点击卡片城市名仍可切换。

创建时选定的 timeZone / city 作为可选元数据保存在 config.json；只在新 profile 缺少对应设置时写入初始值，之后前端已保存的选择优先，避免热重载把地区改回创建时的值。取消新建不会产生实例。城市搜索需要联网，失败时仍可选常用城市。

剪贴板常驻列表不再按估算条数裁剪 DOM：所有已缓存记录都在单列滚动容器中，每行 44 px；放大高度会自然露出更多行。手动 3/4/5 条选项控制视口最大高度，仍可滚动查看其他缓存。左上角分别显示缓存总数与当前完整可见条数；缓存总数为 1 时，放大不会生成不存在的历史。
