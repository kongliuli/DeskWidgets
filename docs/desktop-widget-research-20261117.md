# 有价值的桌面组件候选（2026-11-17）

> 后续决定：网络、开发服务健康、磁盘已暂缓；专注、倒计时、媒体、工作区和随手记已实现。新的候选见 [第二批调研](widget-candidates-round2.md)。下文保留为初次调研记录。

以下是结合当前 DeskWidgets、开发工作场景和常驻资源成本的产品判断，尚未实施。优先做“看一眼就能作决策”的信息，不把桌面变成持续刷新的网页集合。

| 优先级 | 候选 | 主要价值 | 建议最小版本 | 更新与隐私成本 |
| --- | --- | --- | --- | --- |
| P1 | 网络速率与连通性 | 区分网络慢、断线与后台传输 | 当前网卡上下行、60 秒趋势、用户指定地址的延迟 | 速率 1–2 秒；延迟 15–30 秒；不采集访问网址，探测地址显式配置 |
| P1 | 开发服务健康卡 | 不必反复打开终端查看本机服务 | 用户配置的 localhost HTTP 健康入口、响应耗时、上次成功时间 | 5–15 秒；只读探测；暂不放部署、重启、SQL 或任意 shell 按钮 |
| P1 | 专注计时与短待办 | 减少任务切换，适合桌面常驻 | 本地番茄钟、当前一项任务、暂停/完成 | 一秒文本更新；离线；不默认读取其他应用内容 |
| P1 | 磁盘空间与低空间提醒 | 提前发现构建、模型和缓存占满磁盘 | 选定盘符可用/总空间、用户阈值 | 30–60 秒；不用持续扫描目录或文件名 |
| P2 | 下一项日程与倒计时 | 比完整月历更有即时价值 | 本地事件、ICS 文件导入、下一项事件与倒计时 | 分钟级；联网日历另行授权；避免默认展示敏感会议详情 |
| P2 | 媒体播放卡 | 配合本轮音量组件，减少切播放器 | 当前媒体标题、播放/暂停、进度 | 事件驱动优先；只覆盖主动开放系统媒体会话的应用；需验证无打包宿主权限 |
| P2 | 工作区快捷入口 | 一键进入某项目/工作状态 | 用户固定的仓库、目录、URL、现有 .lnk | 用户点击才执行；复用 Windows/PowerToys 快捷方式，避免重写窗口编排器 |
| P2 | 轻量便签 | 随手记录临时信息 | 一张本地便签、自动保存、可选遮挡 | 纯本地；文本写盘防抖；不默认云同步 |
| P3 | 电池与电源状态 | 笔记本有价值，桌面机价值较低 | 电量、充电、系统给出的剩余时间 | 10–30 秒或系统事件；无电池隐藏，不伪造估算 |
| P3 | 用户订阅 RSS 摘要 | 避免常开新闻网页 | 3–5 条标题、手动展开、浏览器打开来源 | 15–30 分钟；可停用；不做无来源推荐流 |
| 暂缓 | 温度、风扇、全面硬件传感器 | 信息丰富但跨设备维护成本大 | 先验证硬件支持与采集权限 | 可能依赖驱动或额外硬件库，暂不混入本轮无驱动利用率组件 |
| 暂缓 | 自动剪贴板/屏幕内容展示 | 有效率价值，但敏感内容暴露风险高 | 若做则显式点击显示、清晰的暂停/遮挡 | 不默认监听并展示密码、令牌、聊天或工作文档 |

建议下一批先做 **网络速率、开发服务健康、专注待办、磁盘空间** 四项。它们用途互补，能采用本机只读数据或用户明确配置的入口，常驻成本也较容易控制。

## 调研依据与实现边界

- 微软对桌面 widgets 的定位是快速查看天气、日程和待办，强调减少打开应用和桌面杂乱；因此上表优先“下一项”与摘要，而不是完整应用搬家：[Windows widgets 使用说明](https://www.microsoft.com/en-us/windows/learning-center/how-to-use-laptop-and-desktop-widgets-on-windows-11)。
- Rainmeter 官方长期提供网络、磁盘等测量能力，网络文档明确区分 bytes/s 与 bits/s；实现时必须标清单位，不能把 Mbps 当 MB/s：[Net measures](https://docs.rainmeter.net/manual/measures/net/)、[FreeDiskSpace](https://docs.rainmeter.net/manual/measures/freediskspace/)、[Measures](https://docs.rainmeter.net/manual/measures/)。
- Windows 系统媒体会话接口可读取播放器公开的会话信息，但文档列出 `globalMediaControl` 能力要求，不能保证任何播放器和当前无打包宿主都直接可用：[RequestAsync](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager.requestasync)。
- PowerToys Workspaces 已支持保存应用布局、创建桌面快捷方式并一键启动。因此启动器应先复用现有快捷方式，而不是重复实现整个工作区管理器：[PowerToys Workspaces](https://learn.microsoft.com/en-us/windows/powertoys/workspaces)。

没有安装第三方工具、读取私人日历/剪贴板或访问业务服务来验证这些候选；上表是公开资料调研与本项目架构判断，不是已交付功能清单。
