# 大、中、小布局与背景

所有背景由 imagegen 单独生成，不把时间、温度或日期烘焙进图片。信息为真实 DOM，背景为可替换插件资源。

| 类型 | 小 | 中 | 大 |
| --- | --- | --- | --- |
| 时钟 | 240×140：地区、时间、日期、时区，主体景物留在底部 | 320×190：时间为视觉中心，夜景作为下方衬景 | 480×280：放大时间和日期，展开更多天空与城市细节 |
| 天气 | 240×180：城市、温度、天气、最高/最低温及状态 | 320×260：增加体感、湿度、风速 | 480×360：放大当前指标、增加各项留白，完整展示分层云景 |
| 黄历 | 240×160：公历日、农历、生肖 | 320×360：增加干支、宜忌和节气 | 460×600：增加冲煞、值神、财神方位、彭祖百忌 |

时钟采用横向构图，天空与左中区域留暗色净空；地球、建筑和街灯集中在下方。天气采用蓝灰天空和柔白云缘，叠加三层慢速云纹理。黄历采用深青水墨山色，山脊位于底部，月光位于侧上方，竖向裁切保留中部文字空间。

背景使用 cover 裁切，默认锚定下方中心；额外渐变遮罩维持文字对比度。用户选择的图片、GIF 和视频仍优先保留。生成图片是静态底图，云层和轻雾由 CSS 动画负责。

正式素材保存在 `widgets/_shared/backgrounds/`：六张 `*-v1.png` 底图，以及带真实 alpha 通道的 `cloud-layer-v1.png` 云层。底图提示词保存在 `background-prompts.json`，透明云层提示词保存在 `cloud-layer-prompt.txt`。均使用内置 image_gen，未使用 CLI/API 回退。

拖动时原组件留在原位，仅显示不抢焦点、鼠标可穿透的蓝色虚框；松开后一次更新真实位置并保存。Esc、关闭或锁定取消此次拖动。这里不修改 Windows 全局“拖动时显示窗口内容”设置。
