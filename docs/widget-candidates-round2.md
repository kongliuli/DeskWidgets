# 第二批桌面组件候选（2026-11-17）

以下是公开资料调研后的产品判断，均未实现。本轮不再推荐已暂缓的网络监控、开发服务健康和磁盘卡。现有系统监控、天气、时钟、音量、随手记、倒计时、专注和工作区入口也不重复列为新功能。

| 顺序 | 候选 | 最小可用形态 | 常驻成本与实施边界 |
| --- | --- | --- | --- |
| 1 | 空气质量 / 紫外线 | 复用南京或用户所选城市，显示 PM2.5、明确标准的 AQI、UV 与未来数小时趋势 | 30–60 分钟刷新；缓存和来源时间必显。Open-Meteo 有这些字段，但其 AQI 是美国/欧洲标准，不能标成中国 AQI；模型格点预测不能冒充南京监测站实测。南京不展示仅限欧洲的花粉数据 |
| 2 | 离线开发小工具 | 时间戳转换、UUID、JSON 格式化/校验、常用单位换算；一个卡片内切换工具 | 仅操作时运行，无轮询、无外部账号；显示输入时区，限制输入长度。UUID 优先复用浏览器 crypto.randomUUID，不自己造随机算法 |
| 3 | 常用片段 / 文本模板 | 标题分组、搜索、点击复制；适合命令样例、路径和回复模板 | 本地保存、用户点击才复制，不自动读取剪贴板；复制命令不等于执行命令。与随手记历史区分：片段长期复用，便签临时记录 |
| 4 | 休息 / 习惯打卡 | 用户自定间隔或每日项目，稍后提醒、今日完成状态 | 本地计时，无联网；优先作为专注组件的扩展，避免再多开一套计时器。提醒是用户自定计划，不给医疗建议 |
| 5 | 临时保持唤醒 | 30/60/120 分钟、不阻止显示器关闭/保持屏幕开启、结束剩余时间 | 明确手动开启、到期释放、退出释放；不永久修改系统电源计划。可参考 PowerToys Awake 的模式，不能宣称能阻止用户主动睡眠或绕过锁屏 |
| 6 | RSS / 更新摘要 | 用户填写来源，保留 3–5 个标题、更新时间、点击打开来源 | 15–30 分钟刷新与离线缓存；正文先不抓取。需验证源的可用性、跨域、XML 安全和请求超时，不能直接把任意网页当 RSS |
| 7 | 电池与电源 | 电量、充电状态、系统提供的容量信息 | 有电池设备才显示，系统不给的时间不自造。Windows 官方 Battery API 有报告与状态通知；台式机/控制器无电池时必须显示不适用 |
| 8 | 色板与取色入口 | 保存 HEX/RGB 色板、点击复制；可给已安装 PowerToys 的取色器做入口 | 色板纯本地且无需截图权限。屏幕取色可优先复用现成工具，不默认常驻抓屏；本轮未检查本机是否安装 PowerToys |

建议先做 **空气质量 + 离线工具箱 + 常用片段**：它们分别补足天气、开发辅助和重复输入，区别于现有卡片，后台成本较低。休息提醒适合合并进专注卡，而不是单独再开一个持续计时组件。

## 依据

- [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api)：PM2.5、UV、美国/欧洲 AQI 与数据模型说明；花粉仅在欧洲花粉季提供。需要保留数据来源归属，若商业化使用再按当时服务条款核对授权。
- [PowerToys Awake](https://learn.microsoft.com/en-us/windows/powertoys/awake)：临时保持系统唤醒、不修改既有电源计划的实现思路。
- [Windows Battery 报告](https://learn.microsoft.com/en-us/windows/apps/develop/devices-sensors/get-battery-info)：读取聚合电池报告和状态变更；电池控制器存在不代表设备一定有电池。
- [PowerToys Color Picker](https://learn.microsoft.com/en-us/windows/powertoys/color-picker)：现成的屏幕取色、颜色历史与格式化复制功能。
- [Windows 剪贴板使用说明](https://support.microsoft.com/en-gb/windows/apps/using-the-clipboard)：系统已有历史与同步能力，因此建议新增的是用户主动维护的模板库，不默认复制一套后台监听历史。

本调研未访问私人订阅、读取剪贴板、操作电源设置、安装工具或开通第三方账号。上述成本与优先级是设计判断，API 资料可用不等于本机集成已验证。
